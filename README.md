# AI Agent 随身导师

基于开源课程 [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch)（20 个 Phase / 523 节课）的**中文 AI 导师**应用：手机上随时打开，用对话方式把 AI Agent 知识学完，带进度追踪、断点续学与个性化推荐。

- 内容来源：`rohitg00/ai-engineering-from-scratch`（MIT）
- 本应用定位：该课程的**中文导学外壳**，课程原文版权归原作者
- 技术形态：纯静态、零构建、零依赖，进度存在本机浏览器

---

## 快速开始

```bash
# 方式一：双击 index.html 直接用（file:// 也能跑）

# 方式二：起个本地服务（推荐，手机同一 Wi-Fi 可访问）
cd ai-agent-mentor
python -m http.server 8123
# 电脑：http://127.0.0.1:8123
# 手机：http://<你的内网IP>:8123
```

部署（想在手机上随时随地访问必看）：把整个目录丢到任意静态托管即可，无需后端，
还能"添加到主屏幕"变成离线 App。步骤见 [DEPLOY.md](./DEPLOY.md)（GitHub Pages / Vercel / 腾讯云 / Nginx / PWA）。

## 五个功能怎么落地

### 1. 对话式学习

- 导师按**分步骤脚本**讲解：钩子 → 为什么重要 → 3~5 个要点（说「继续」逐条推进）→ 小测 → 动手任务
- 自由问答：概念解释、故障排查、技术选型都能问，答案锚定到具体课程
- 已内置 25 节精编中文讲解 + 16 张概念卡（Agent 循环、ReWOO、Reflexion、MCP、Agent Skills、提示注入、评测……）
- **可选接模型**：在「我的 → 模型接入」填 OpenAI 兼容的 Base URL / Key / 模型，导师会用检索到的课程片段作为上下文作答；不填则完全离线可用，断网照学

### 2. 学习进度追踪

| 追踪项 | 说明 |
|---|---|
| 已学章节 | 每节课有 `未学 / 学习中 / 已掌握` 三态 |
| 掌握度 | 0-100，答对 +18、答错 −8，≥80 自动判定掌握 |
| 学习时长 | 页面可见时按 30 秒粒度累计，按天聚合 |
| 断点续学 | 记录讲到第几步，首页「断点续学」一键回到上次位置 |
| 连续天数 | 当天学习 ≥1 分钟即计入 |

### 3. 个性化推荐

按优先级出队：**到期复习 → 错题巩固 → 断点续学 → 当前路线下一节 → 目标方向 → 未学课程**

- 首次进入选「目标 + 每天时长」，推荐会按可用时长过滤（只有 5 分钟就只推短课）
- 错题与答错记录会汇总成「薄弱环节（按 Phase）」，反向影响推荐
- 间隔重复：掌握度越高复习间隔越长（1 / 3 / 7 / 16 天）

### 4. 移动端优先

- 底部 5 Tab 单手可达，核心功能一步进入
- 响应式 + 深色模式 + iPhone 安全区适配
- 大按钮、圆角卡片、选择题直接点选项，不做复杂手势

### 5. 简洁易用

- 首页就是「今天学这个」+ 一个「开始学」按钮
- 对话里所有操作都是可点的动作按钮（继续 / 考我 / 看原文 / 标记掌握）
- 常见问题做成 chips，点一下直接提问
